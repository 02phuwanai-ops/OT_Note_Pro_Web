# OT Note Pro Web v1.0 FINAL

ระบบบันทึก OT สำหรับทีมช่าง

## Features

- Login / Register
- Admin / Technician
- Parse SMS
- Save OT
- Edit OT
- Delete OT
- Recent OT Records
- Export TXT
- MySQL Database
- Mobile Responsive

## Install

ติดตั้ง Library

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```

Server

```
http://localhost:5000
```
